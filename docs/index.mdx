Terrarium is a 2D hex-world MMO where you deploy **WebAssembly creatures** that compete for energy. Code is immutable after deploy; death matters.

## How it works

1. **Sign in** at [terrarium-506917.web.app](https://terrarium-506917.web.app) and click an empty cell.
2. **Code in Replit** — Zig SDK, AI assistants, one-click build.
3. **Run** — compiles WASM and deploys to your cell via API key.

The server accepts **prebuilt WASM** (Zig, Rust, etc.) or **WAT** text for low-level experiments. Zig via Replit is the recommended path.

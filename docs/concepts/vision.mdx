Terrarium is a **persistent simulation** — not a game with scores, factions, or win conditions.

## Principles

- **Bare bones** — minimal primitives; emergence over mechanics
- **Real stakes** — death matters; code is immutable after deploy
- **Open spectating** — everyone watches live; source is private to the owner
- **Deflationary** — energy is destroyed continuously; free mint is capped

## World

Sparse hex grid, always-on server, creatures with energy/health/facing. One action per tick.

The **Rust SDK** powers [Creature Studio](/getting-started/studio): edit a full Rust module, compile via the isolated worker, test in the Tests tab, deploy WASM to the live world.

Repo: [sdk/rust/](https://github.com/tsuberim/terrarium/tree/main/sdk/rust)

## In-game (recommended)

1. Sign in → **Studio** in the HUD
2. **Source** tab — creature logic (`move_forward();`, `loop { ... }`, or `pub fn main() { ... }`); prelude imports are injected automatically
3. **Tests** tab — `#[terrarium::test]` blocks for sandbox checks
4. **Run test** → preview → pick map cell → **Deploy**

See [Creature Studio](/getting-started/studio).

## Source shape

```rust
move_forward();
rotate(1);
```

Or use an explicit loop:

```rust
loop {
    move_forward();
    rotate(1);
}
```

The compile worker injects `use terrarium_sdk::prelude::*` and wraps your source in `pub fn main()` when needed. A bare `move_forward();` moves once, then halts when `main` returns after the slice resumes.

**One action per tick** — only the first move/eat/rotate call in a tick runs. The host resumes your program each tick until a slice ends.

## Local compile worker

```bash
./scripts/run-compile-worker.sh   # :8081
COMPILE_WORKER_URL=http://127.0.0.1:8081 ./scripts/dev.sh
```

## CLI sandbox

```bash
export TERRARIUM_API_BASE=http://localhost:8080/api
export TERRARIUM_API_KEY=tr_…   # or Firebase ID token
./sdk/rust/scripts/sim.sh path/to/user.rs
```

## Crate layout

| Path | Role |
|------|------|
| `terrarium-sdk/` | Host imports + helpers (`terrarium::prelude`) |
| `scripts/sim.sh` | Compile + sandbox via HTTP API |

## Alternatives

- **Upload WASM** in Studio — any `wasm32-unknown-unknown` build
- **API keys** — deploy via `POST /v1/deploy` ([Deploy from the game](/getting-started/deploy-from-game))
- **WAT** — raw WebAssembly text in the `code` field (advanced)

Host syscalls: [Host ABI](/reference/host-abi).

Code is **immutable** after deploy.

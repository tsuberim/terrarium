Creatures are **WebAssembly modules** with three `"terrarium"` imports and a fixed **ABI memory page** at offset 4096.

## Design

- **Simple** — one 64-byte envelope, one page, three imports (`act`, `recv`, `rand`).
- **Efficient** — guest writes a single Action slot; no pointer args or dozens of syscalls.
- **Extensible** — new action `kind` values and appended Self fields without breaking old modules.

Full spec (memory map, gas, costs): internal [host ABI v2](https://github.com/tsuberim/terrarium/blob/main/docs/internal/engineering/sim/host-abi.md).

## Module contract

| Export | Role |
|--------|------|
| `memory` | ≥ 8 KiB linear memory |
| `main` | `() -> ()` — resumed each sim tick until slice ends |

## Imports

| Import | Effect |
|--------|--------|
| `act()` | Read guest **Action** slot (64 B); queue one world action; yield on success |
| `recv()` | Pop inbox into host-written **Inbox** slot; returns 1 if message |
| `rand()` | Pseudorandom u64 (seed: creature id + tick) |

Reads (self, tiles, vision, init) are **memory only** — host refreshes each tick.

## Slice execution

Each tick runs until: first successful `act()` (suspend with one action), opcode **gas** exhausted (suspend), or `main` returns (**suicide**).

## Gas & energy (summary)

| Cost | Default |
|------|---------|
| Opcode gas | 1 energy per WASM opcode, max 25 000 opcodes/tick |
| Move / dig / place / hit / rotate | +25 000 energy each (`act` surcharge) |
| Health regen (idle) | +25 000 when healing |
| Corpse floor | 1 000 000 energy — at or below → death |

Eat and spawn **transfer** energy; signal/broadcast have no extra surcharge beyond gas.

See [Energy & glims](/concepts/energy) for the player-facing economy.

## Authoring

Use **Creature Studio** (Rust → WASM) or upload WASM via deploy. There are no bundled example programs in the repo.

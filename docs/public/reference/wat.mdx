<Warning>
  WAT is for advanced experiments. Use [Creature Studio](/getting-started/studio) (Rust) or [Zig in Replit](/getting-started/replit) for normal authoring.
</Warning>

Creatures are **WebAssembly modules**. WAT (WebAssembly text) can be compiled on deploy for low-level work; most authors use Studio or upload prebuilt `.wasm`.

## Minimal module

```wat
(module
  (import "terrarium" "sleep" (func $sleep))
  (func (export "tick") (call $sleep))
)
```

**Creature Studio** is the default way to author creatures. Sign in, open **Studio** from the HUD, edit Rust, run tests in the sandbox preview, then **Deploy** to a map cell.

<Steps>
  <Step title="Sign in">
    Use Google sign-in (or the local auth emulator in dev). Studio requires an account.
  </Step>
  <Step title="Open Studio">
    Click **Studio** in the HUD. **Source** tab holds your creature module; **Tests** tab holds `#[terrarium::test]` blocks.
  </Step>
  <Step title="Run tests">
    Pick a test and click **Run test** — compiles Source + runs the sandbox scenario in the preview pane. Use **Play** / **Stop** to replay frames.
  </Step>
  <Step title="Pick a cell">
    Click an **empty hex** on the world map (right of the studio pane). The status bar shows coordinates.
  </Step>
  <Step title="Deploy">
    Click **Deploy**, set extra glims if needed, confirm. Total cost = corpse base + extra; debited from your balance.
  </Step>
</Steps>

## Default source shape

```rust
use terrarium_sdk::prelude::*;

loop {
    let _ = move_forward();
    let _ = rotate(1);
}
```

Module-level `static mut` and WASM locals persist between ticks — the host resumes the same fiber each sim tick. Use `break` (or return from `main`) to end the creature voluntarily.

## Alternatives

- **Upload WASM** — drop a `.wasm` file in Studio (skips compile)
- **API keys + CLI** — see [Deploy from the game](/getting-started/deploy-from-game)

## Code is immutable

Programs cannot be edited after deploy. **Suicide** returns remaining energy to your credits.

See [Host ABI](/reference/host-abi) for syscalls and [API reference](/api-reference) for deploy endpoints.

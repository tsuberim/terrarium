Terrarium is a 2D hex-world MMO where you deploy **WebAssembly creatures** that compete for energy. Code is immutable after deploy; death matters.

## How it works

1. **Sign in** at [terrarium-506917.web.app](https://terrarium-506917.web.app).
2. **Open Studio** — edit Rust, run **Test** scenarios, preview in sandbox.
3. **Deploy** — pick an empty cell, pay glims, creature runs on the live 2 Hz world.

External authors can use **Zig + Replit** or upload prebuilt **WASM**. Advanced: raw **WAT** for experiments.

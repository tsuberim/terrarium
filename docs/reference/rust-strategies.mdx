The `strategies/` directory contains Rust examples compiled to WASM with `./scripts/build-strategies.sh`.

This path is **advanced** — the recommended SDK is [Zig](/reference/zig-sdk) with [Replit](/getting-started/replit).

The server does not compile Rust. Build locally or in CI, then upload `.wasm` via the [deploy dialog](/getting-started/deploy-from-game) or `POST /v1/deploy`.
